# Command line

Two commands, one per package. Both run on plain Node 22 or later. Exit code 0 on success, 1 when a check or an operation fails, 2 for usage errors. Everything diagnostic goes to stderr; stdout carries the result, so `--json` output can be piped.

## `agent-custody`

| command | what it does | page |

| `delegate --key <agent.key> --parent <grant.json> --agent <sub> --scopes <a,b> [--ttl-hours N] [--agent-key <sub.pub>] --out <file>` | a narrower grant for a sub-agent | [gateway](./gateway#delegation-chains) |
| `console --config <gateway.json> [--port 8795] [--host 127.0.0.1] [--token-env CONSOLE_TOKEN] [--gateway-url <url>] [--state-dir <dir>]` | the admin console for a gateway, a separate service behind a token read from the environment: its config and tools, the config check, receipts with a verdict each, a policy editor that validates and replays recorded calls before it saves, grant inspection and revocation, and an audit trail. | `check --config <gateway.json> [--connect] [--json]` | what the gateway would fail on at startup, found before it starts: the config (and unknown keys), the keys, the Cedar policy, the grant, the credential variables, stdio commands, and writable paths. `--connect` also starts the upstreams, catches tool-name collisions and unreachable servers, and checks every tool name the config and grant mention against the tools offered. Exits 1 on an error | [configuration](/receipts/configuration#check-it-before-you-start-it) |
| `revoke --config <gateway.json> --grant <grant.json>` | appends the grant's digest to the config's `revokedGrants` file, by rename; a running gateway refuses it, and every grant delegated from it, on the next call | [gateway](./gateway#running-it) |
| `reconcile --config <gateway.json> --operation <uuid>` | reads the provider's operation record; commits a linked reconciliation receipt before closing a financial reservation; prints `{ operation, status, receipt }` | [gateway](./gateway#financial-operations) |
| `policy simulate --policy <proposed.cedar> --receipts <dir> --issuer-key <pub>… [--principal-key <pub>]… [--approval-key <pub>]… [--log-key <pub>]… [--capture-key-env NAME] [--disclose <file>]… [--json] [--out <report.json>]` | verifies local receipt bundles, one at a time (a receipt whose id does not match its file name fails the command), and replays their recorded calls against the proposed policy; groups changed decisions by tool and reason with receipt ids, records the proposed policy digest; a call with only an authorization file, or with withheld inputs that the key or disclosures do not open, is skipped and the replay exits 1 | [policies](https://agent-custody.dev/receipts/policies#simulating-a-policy-against-recorded-history) |
| `gateway --config <gateway.json> [--http [--port 8790] [--host 127.0.0.1] [--idle-minutes 30]]` | the gateway over stdio, or shared over HTTP | [gateway](./gateway#running-it) |
| `gateway --config <gateway.json> --a2a [--port 8790] [--host 127.0.0.1]` | the gateway as an A2A agent in front of the config's one `a2a` upstream | [gateway](./gateway#running-it) |
| `hook [--config <sdk.json>]` | the Claude Code hook; the event on stdin | [Claude Code](./claude-code) |
| `serve --config <sdk.json> [--port 8788] [--host 127.0.0.1]` | the sidecar | [sidecar](./sidecar) |
| `verify <bundle.json> --issuer-key <pub> [--principal-key <pub>] [--approval-key <pub>] [--log-key <pub> \| --log-url <url>] [--log-id <id>] [--require-strict] [--upstream-key <pub>] [--stripe-secret-env NAME] [--github-secret-env NAME] [--log <log.jsonl>] [--disclose <file>] [--capture-key-env NAME] [--json]` | checks one receipt | [verify](./verify#verify) |
| `reveal <bundle.json> --capture-key-env NAME --issuer-key <pub> [--out <file>] [--include-salts]` | the values a receipt withheld under a capture rule, decrypted with the customer's key, as a disclosure file for `verify --disclose` | [verify](./verify#reveal) |

| `log --db-env NAME (--key <log.key> [--retired-key <pub>]… \| --signer-url <url> [--signer-token-env NAME]) [--checkpoint-dir <dir>] [--checkpoint-every 300] [--checkpoint-heartbeat 21600] [--admin-token-env NAME] [--public-url <url>] [--checkpoints-url <url>] [--trust-proxy]` | the log server over Postgres, with tenants, checkpoints, and the admin page | [log API](./log-api#the-server) |

| `witness --key <witness.key> --log-url <url> --checkpoints-url <url> --out <dir> [--tenant <name>]… [--every 300] [--once]` | a second signer on another operator's machine | [log API](./log-api#the-witness) |
| `anchor --log-url <url> --checkpoints-url <url> --out <dir> --rpc-url-env NAME --key-env NAME [--tenant <name>]… [--chain ethereum\|base\|arbitrum\|optimism\|polygon\|<id>] [--max-fee-gwei <gwei>] [--every 21600] [--once]` | commits the log's checkpoints to an EVM chain, Ethereum by default, one transaction per run that has something new | [log API](./log-api#the-anchor) |
| `log-check --log-url <url> [--checkpoints-url <url>] [--witness-url <url>] [--tenant <name>]… [--max-lag 900] [--anchor-url <url> --anchor-address <0x…> --anchor-rpc-env NAME… --anchor-log-id <tenant>=<id>… [--anchor-chain ethereum] [--max-anchor-lag 46800]] [--json]` | the outside monitor | [log API](./log-api#monitoring) |

| `portal --db-env NAME --secret-env NAME --public-url <url> [--checkpoints-url <url>] [--portal-url <url>] [--stripe-key-env NAME --stripe-webhook-env NAME --stripe-price-team <id>] [--mail-key-env NAME --mail-from <address> [--mail-notify <address>]] [--trust-proxy]` | the tenant portal; mail through Resend's API at registration | [hosted](./hosted#registering-the-portal) |

| `log-admin --db-env NAME user mfa-reset <email>` | turns MFA off for a portal account that lost its authenticator | [hosted](./hosted#two-step-sign-in) |
